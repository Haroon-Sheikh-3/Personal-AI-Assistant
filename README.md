# 🤖 Autonomous Voice-Controlled AI Desktop Assistant

An experimental local desktop assistant built with Python that listens for voice commands and executes automated tasks.

> ⚠️ **Status:** Active Development (Phase 1)

## 📌 Phase 1 Progress
- [x] Basic speech recognition and audio capture setup
- [x] Initial command parser and module architecture
- [ ] Integration with Claude/LLM API for context processing
- [ ] Desktop automation triggers (file system, app launching)

## 🛠️ Tech Stack
- Python 3.x
- SpeechRecognition / Audio Processing APIs
- LLM API Integrations
